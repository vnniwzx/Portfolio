## Abrir no seu computador (opcional)

1. Clique no botão verde **Code** e depois em **Download ZIP**.
2. Extraia o arquivo.
3. Dê dois cliques em `index.html`.

## Arquivos

```
Portfolio/
├── index.html      conteúdo do site
├── style.css       cores, layout e animações
├── script.js       tema, animações e botão de copiar e-mail
├── foto.jpg        minha foto
├── img/banner.png  banner (usado também no README do perfil)
├── img/skills/     logos das linguagens e ferramentas
├── curriculo.pdf   currículo para download
└── README.md       este arquivo
```

Para trocar a foto, substitua `foto.jpg` por outra com o mesmo nome (de preferência na vertical, 4:5).

Feito com HTML, CSS e JavaScript puros, sem framework.
