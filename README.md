# Portfólio | Vinicius Furtado

Portfólio pessoal de **Vinicius Furtado**, desenvolvedor Full Stack em formação no curso técnico de **Desenvolvimento Full Stack da FIAP School**.

O site apresenta quem eu sou, minhas habilidades, meus projetos, minhas paixões e os sonhos que quero conquistar na carreira. O visual mistura o estilo de um lookbook de moda com elementos de games, que foram onde começou meu interesse por tecnologia.

🔗 **Acesse o site:** https://vnniwzx.github.io/Portfolio/

---

## Seções do site

| Seção | O que mostra |
|---|---|
| **Início** | Nome, foto, área de atuação e atalhos para projetos, GitHub e LinkedIn |
| **Sobre mim** | Minha história, dos games até o código, com uma linha do tempo |
| **Skills** | Tecnologias em formato de "inventário" com barras de nível, além das competências interpessoais |
| **Idiomas** | Português (nativo), inglês (avançado) e francês (intermediário) |
| **Projetos** | Repositórios do GitHub com filtro por linguagem |
| **Paixões** | Moda, carros e música |
| **Sonhos** | Metas da carreira, da Zona Leste até a Paris Fashion Week |
| **Contato** | E-mail, WhatsApp, LinkedIn e GitHub |

## Tecnologias usadas

- **HTML5**: estrutura e conteúdo
- **CSS3**: layout responsivo, animações e tema claro/escuro automático
- **JavaScript**: interações (texto digitado, filtro de projetos, efeito 3D na foto, botões de copiar)
- **Google Fonts**: Archivo, Bodoni Moda e JetBrains Mono

Não usa nenhuma biblioteca nem framework. É só HTML, CSS e JavaScript puros.

## Estrutura dos arquivos

```
Portfolio/
├── index.html   → estrutura e conteúdo do site
├── style.css    → estilos, cores e animações
├── script.js    → interações do site
├── foto.jpg     → foto de perfil
└── README.md    → este arquivo
```

## Como acessar

### Pela internet

Abra o link: **https://vnniwzx.github.io/Portfolio/**

### No seu computador

1. Clique no botão verde **Code** e depois em **Download ZIP**, ou clone o repositório:
   ```bash
   git clone https://github.com/vnniwzx/Portfolio.git
   ```
2. Extraia a pasta, se tiver baixado o ZIP.
3. Abra o arquivo **index.html** no navegador (Chrome, Edge, Firefox etc.).

Todos os arquivos precisam ficar na mesma pasta para o site carregar o estilo, os scripts e a foto.
